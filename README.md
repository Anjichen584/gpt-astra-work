# 🌑 BloodMoon 血月

一个为 **Paper 1.21.10** 打造的重量级血月插件。血月之夜，魔物被血光浸染，精英与领主降临，灾厄随机降下——活到黎明，才有资格分享血月的馈赠。

> 成品位置：`dist/BloodMoon-1.0.0.jar`（由 GitHub Actions 用 Gradle 自动构建）

## ✨ 玩法总览

### 🌒 血月五阶体系
每晚有概率触发血月（满月大幅加成，可配置只在满月触发）。血月分五个阶层，权重随机：

| 阶层 | 名称 | 怪物血量 | 怪物攻击 | 精英概率 | 经验加成 |
|---|---|---|---|---|---|
| 1 | 猩红之月 | ×1.3 | ×1.2 | 6% | ×1.5 |
| 2 | 泣血之月 | ×1.6 | ×1.4 | 10% | ×2.0 |
| 3 | 屠戮之月 | ×2.0 | ×1.7 | 15% | ×2.5 |
| 4 | 梦魇之月 | ×2.5 | ×2.0 | 20% | ×3.0 |
| 5 | 天启之月 | ×3.2 | ×2.5 | 28% | ×4.0 |

血月期间：Boss 血条显示夜晚进度、禁止睡觉、雷暴、全程血雾粒子与心跳环境音、周期性"刷怪压力"、高阶血月怪物成群出现并随机穿戴附魔装备。

### ⚔ 11 种精英魔物（模型全部由插件自配：体型/装备/染色皮甲/坐骑/红色发光/技能）
- **血月屠夫** — 巨型僵尸，猛扑突进 + 撕裂凋零
- **猩红猎手** — 火焰强力弓骷髅，会闪现到你身后
- **瘟疫使者** — 女巫，投掷剧毒之雾
- **骸骨骑士** — 骷髅骑乘巨型蜘蛛
- **爆裂魔灵** — 高压快引信闪电苦力怕
- **噬魂魔翼** — 巨型幻翼，尖啸加速
- **血月碾压兽** — 劫掠兽，近身怒吼击飞
- **缚魂术士** — 唤魔者，召唤恼鬼与尖牙
- **溺渊拖行者** — 三叉戟溺尸，激流突刺
- **焦骨浪人** — 下界合金剑凋灵骷髅，点燃目标
- **血月小丑骑士** — 鸡骑士突击手

### 👑 血月领主 · 卡尔诺斯
高阶血月午夜降临的多阶段 Boss：冲击波击飞、凋灵之首弹幕、召唤仆从、生命汲取；66%/33% 血量进入狂暴/最终形态。击杀必掉血月神器 + 战利品雨 + 烟花庆典。

### 🎲 8 种随机灾厄事件
陨星雨 / 尸潮涌动 / 血雾弥漫 / 猩红雷罚 / 血月赐福(正面) / 蝠群蔽月 / 空投血匣(限时宝箱+守卫) / 引力紊乱。

### 💎 血晶经济 + 血月黑市
血月魔物掉落 **血月残晶**，精英必掉、领主巨量掉落。`/bm shop` 打开黑市购买装备，也可以直接用残晶合成。

### 🗡 7 种自定义物品
- **血月之刃** — 15% 吸血，血月期间对亡灵 +30% 伤害
- **猩红战弓** — 血雾箭迹，命中点燃+凋零
- **守夜人护符** — 放包里即可：血月期间抗性+防火
- **血月图腾** — 触发时血爆击退群怪并回复
- **血浆凝块** — 右键急救
- **猎人号角** — 右键显形 30 格内所有魔物（60s CD）
- **血月残晶** — 货币本体

### 🏆 结算与排行
第一滴血播报、连杀里程碑（10/25/50）、黎明幸存奖励、战绩持久化、五种排行榜。

## 📜 命令
| 命令 | 说明 | 权限 |
|---|---|---|
| `/bm status` | 查看血月状态 | bloodmoon.use |
| `/bm shop` | 打开血月黑市 | bloodmoon.use |
| `/bm stats` | 个人战绩 | bloodmoon.use |
| `/bm top <kills\|elites\|boss\|nights\|shards>` | 排行榜 | bloodmoon.use |
| `/bm start [1-5]` | 强制开启血月 | bloodmoon.admin |
| `/bm stop` | 强制结束 | bloodmoon.admin |
| `/bm boss` | 召唤血月领主 | bloodmoon.admin |
| `/bm spawn <精英>` | 召唤指定精英 | bloodmoon.admin |
| `/bm give <数量>` | 给自己残晶 | bloodmoon.admin |
| `/bm reload` | 重载配置 | bloodmoon.admin |

别名：`/bloodmoon`、`/bm`、`/xueyue`

## 🔧 构建 & 安装
```bash
gradle build        # 需要 JDK 21
# 产物: build/libs/BloodMoon-1.0.0.jar
```
把 jar 丢进 Paper 1.21.10 服务器的 `plugins/` 目录即可。所有数值都在 `config.yml` 中可调。
